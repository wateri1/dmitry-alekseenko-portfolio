## 🌟 Ключевые особенности проекта

1. **Маркетинговая логика (Value-First)**:
   * Фокус на мобильных пользователей (8 из 10 посетителей заходят со смартфонов).
   * Скорость загрузки до 1.5 секунд (чистый HTML5/CSS3/JS без тяжелых фреймворков).
   * Прямая связь в WhatsApp с предзаполненными контекстными сообщениями под каждую услугу.

2. **Архитектура «Сайт = 16:9 PDF Презентация»**:
   * Каждый смысловой блок сверстан в пропорциях слайда 16:9 (`<section class="slide-section">`).
   * Встроенные правила `@media print` с `size: 16in 9in` и `break-after: page`.
   * Возможность в один клик сгенерировать готовое коммерческое PDF-предложение для отправки клиентам в мессенджерах через кнопку «Экспорт в PDF».

3. **Швейцарская модульная дизайн-система**:
   * Цветовая палитра: теплый бумажный минимализм (`#F6F5F2`), контрастный угольный (`#141413`) и терракотовый акцент (`#E04F26`).
   * Типографика: шрифтовые пары Google Fonts (`Unbounded`, `Onest`, `JetBrains Mono`).
   * Тонкие структурные разделители 1px (`#D8D5CD`) без дешевого неонового блюра и шаблонных теней.

4. **Интерактивные виджеты**:
   * **Экспресс-калькулятор стоимости за 30 секунд** с автогенерацией индивидуального брифа в WhatsApp.
   * **Аккордеоны с нулевым сдвигом макета (CLS = 0)** для FAQ и модулей программы курса.
   * **Модальные окна живого демо** в стиле MacOS Window Chrome.
   * **Липкая мобильная кнопка WhatsApp** с поддержкой Safe Area (iPhone X–16).

5. **SEO и структурированные данные Schema.org**:
   * Микроразметка `ProfessionalService`, `HowTo` (5 шагов процесса) и `FAQPage`.
   * Полные метатеги Open Graph и Twitter Cards для презентабельных превью-карточек в Telegram и WhatsApp.

## 🚀 Быстрый старт локально

```bash
# Клонировать репозиторий
git clone https://github.com/wateri1/dmitry-alekseenko-portfolio.git

# Перейти в папку проекта
cd dmitry-alekseenko-portfolio

# Запустить любой локальный статический сервер, например:
python -m http.server 3000
# или
npx serve .
```

Откройте в браузере: `http://localhost:3000`
