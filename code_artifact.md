## 3. Дизайн-система и стилистика (Этап 3)

### Визуальная концепция: Швейцарский минимализм / Редакционный стиль
Отказ от нейросетевых штампов: никаких темных фонов с неоново-фиолетовыми свечениями (`glow`), размытого стекла (`glassmorphism`), одинаковых карточек по 3 в ряд с иконками в кружочках и выравнивания всего текста по центру.

### Цветовая палитра (HEX)
* **Основной фон страницы (Background Primary):** `#F6F5F2` (Теплый бумажный / каменный — не слепит глаза и дорого смотрится в PDF).
* **Вторичный фон карточек (Surface / Card):** `#ECEAE4` (Мягкий песочно-серый).
* **Цвет линий и разделителей (Border 1px):** `#D8D5CD` (Четкая структурная сетка без грязных теней `box-shadow`).
* **Основной цвет текста и контрастных блоков (Text Primary / Dark Block):** `#141413` (Глубокий угольный).
* **Второстепенный текст (Text Secondary):** `#5C5B57` (Приглушенный графит).
* **Единственный акцентный цвет (Accent Primary):** `#E04F26` (Инженерный терракотово-оранжевый — для главных кнопок WhatsApp, ховеров и ключевых маркеров). *Альтернатива: Глубокий кобальтовый `#1D4ED8`.*

### Типографика (Google Fonts)
1. **Заголовки (H1, H2, H3):** `Unbounded` (Medium 500 / Bold 700) или `Manrope` (ExtraBold 800).
   * *Настройки:* Плотное межбуквенное расстояние (`letter-spacing: -0.03em`), межстрочный интервал `line-height: 1.08–1.15`.
2. **Основной текст (Body, карточки, FAQ):** `Onest` или `Golos Text` (Regular 400 / Medium 500).
   * *Настройки:* Комфортная длина строки `60–65ch`, `line-height: 1.55`.
3. **Технические метки (Номера блоков, сроки, теги):** `JetBrains Mono` (Regular 400 / Medium 500).
   * *Настройки:* Верхний регистр (`uppercase`), `font-size: 12px–14px`, `letter-spacing: 0.05em`.

## 4. Технические рекомендации для верстки и режима презентации (Этап 4–5)

1. **Модульная сетка (Bento / Swiss Grid):**
   * Используй контейнер максимальной ширины `1280px` или `1360px` с отступами по краям `24px` (на мобильных `16px`).
   * Разделяй секции и колонки тонкими линиями `1px solid #D8D5CD`.
   * Кейсы верстай широкими горизонтальными блоками (например, 5 колонок под описание и 7 колонок под крупное превью интерфейса).
2. **Подготовка к трансформации в презентацию (PDF / Pitch Deck):**
   * Каждую из 6 основных секций оберни в тег `<section class="slide-section">`.
   * Добавь в CSS правила для печати/экспорта в PDF:
     ```css
     @media print {
       @page {
         size: 16in 9in; /* Формат презентации 16:9 */
         margin: 0;
       }
       body {
         background-color: #F6F5F2 !important;
         -webkit-print-color-adjust: exact;
         print-color-adjust: exact;
       }
       .slide-section {
         min-height: 100vh;
         page-break-after: always;
         break-after: page;
         display: flex;
         flex-direction: column;
         justify-content: center;
         padding: 48px 64px;
       }
       .no-print {
         display: none !important;
       }
     }
     ```
3. **Прямая ссылка на WhatsApp:**
   * Формат ссылки для всех кнопок с предзаполненным сообщением, чтобы клиенту было проще начать диалог:
     `https://wa.me/77000000000?text=Здравствуйте,%20Дмитрий!%20Пишу%20с%20вашего%20сайта-портфолио.%20Хочу%20обсудить%20разработку%20сайта.` *(замени номер на свой реальный)*.
